1. Концепція гри (Game Pitch)
Battleship.io — це класична гра "Морський бій", реалізована як сучасний вебдодаток, що не потребує встановлення. 
Гра вирізняється унікальним ретро-дизайном: візуальний стиль та звукове оформлення імітують роботу за аналоговим тактичним радаром часів холодної війни. 
Гравець бере на себе роль оператора радара, що додає глибокого занурення (immersion) у класичний ігровий процес.
Також гра має систему досягнень, та декілько пасхалок у головному меню.

2. Концептуальна цілісність: Core Loop (Основний ігровий цикл)
Ігровий цикл складається з трьох послідовних фаз, які замикаються до моменту перемоги або поразки:

Підготовка: Розміщення флоту на сітці 10х10 (вручну або автоматично).
Тактична фаза (Бій): Обмін пострілами з супротивником. Аналіз влучань ("Мимо", "Поранений", "Знищений").
Ескалація (Твік): Використання "Суперудару" для перелому ходу битви.
Резолюція: Визначення переможця після знищення останнього корабля, повернення в Головне меню для нового матчу.

3. Player Flow (UX-проектування)
Шлях гравця спроєктований для мінімізації кліків до початку гри:

Гравець заходить на сайт

Головне меню -> Налаштування гучності (за потреби) -> Натискання "Грати" -> Обирання нікнейму, ігрової кімнати, та режиму гри (PVP або PVE)

Екран розстановки -> Гравець натискає "Авторозстановка" для економії часу або розставляє кораблі кліками -> Натискає "Бій".

Екран бою -> Почергові кліки по ворожому полю -> Візуальний та звуковий фідбек -> Перемога чи програш.

4. Механіки та системи (Тестовані вимоги)
Усі наведені нижче вимоги можуть бути перевірені за принципом "виконано/не виконано".

4.1. Ігрове поле та Флот
[Вимога] Гра генерує два поля розміром 10х10 клітинок (одне для гравця, одне для супротивника/ШІ).

[Вимога] Флот кожного гравця складається з: 1 лінкора (4 кл.), 2 крейсерів (3 кл.), 3 есмінців (2 кл.), 4 катерів (1 кл.).

[Вимога] Система не дозволяє розміщувати кораблі так, щоб вони торкалися один одного бортами або по діагоналі.

4.2. Базовий процес гри (Стрільба)
[Вимога] Гравець може натиснути на невідкриту клітинку ворожого поля, щоб здійснити постріл.

[Вимога] Якщо постріл не влучив, клітинка помічается крапкою ("Мимо"), а хід переходить до супротивника.

[Вимога] Якщо постріл влучив, клітинка змінює колір на червоний ("Влучення"), а гравець отримує право додаткового ходу.

[Вимога] Якщо корабель повністю знищений, всі сусідні навколо нього клітинки автоматично позначаються як "Мимо" (ореол).

4.3. Додаткові механіки (Твіки)
[Вимога] Авторозстановка: При натисканні кнопки "Авторостановка", система миттєво генерує випадкове, але правильне (за правилами) розміщення всіх кораблів флоту гравця.

[Вимога] Зброя "Суперудар" (Area Attack 3x3): Гравець має доступ до однієї спеціальної атаки на гру. При її активації та кліку на поле, гра одночасно перевіряє на влучання зону розміром 3х3 клітинки навколо епіцентру кліку. Після використання кнопка "Суперудар" стає неактивною.

5. Пріоритезація та Scope Management (MoSCoW)
Для забезпечення стабільності білда в умовах обмеженого часу Game Jam, обсяг робіт поділено наступним чином:

Must-have (Критично для гри):

Генерація поля 10х10 та базова розстановка.

Почергова стрільба з фіксацією станів (Пусто/Промах/Влучив/Знищив).

Умови перемоги/поразки.

Адаптивний UI та стилістика радара.

Should-have (Важливо для Game Feel та UX):

Авторозстановка кораблів (економія часу гравця).

Трясіння екрану (Screen Shake) при знищенні корабля.

Звуковий супровід та шуми (CRT-ефект, ембієнт).

Could-have (Додатковий функціонал - Твіки):

Механіка "Суперудар 3х3".

Система досягнень (Achievements) з локальним збереженням прогресу.

Won't-have (Відкладено для збереження стабільності):

Мережевий мультиплеєр (тільки гра проти ШІ або Hotseat).

Зміна розмірів поля (більше 10х10).

6. Аудіо-візуальний стиль (Art & Sound Cohesion)
Уся гра витримана в єдиному стилі терміналу:

Колірна палітра: Чорний фон (космос/глибоководдя), темно-зелена сітка, яскраво-зелений акцентний текст (Phosphor Green), темно-червоний для влучань.

Шрифти: Моноширинний піксельний шрифт.

Звук: Синтезовані гудки (Web Audio API) для UI-елементів, генеративний "білий шум" для ефектів вибуху, аналоговий шум на фоні. Музичний супровід вимикається/регулюється в налаштуваннях.
